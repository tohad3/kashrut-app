# ניהול כשרות ב-Google – מדריך הקמה

אותה שיטה כמו מערכת קליטת העסקים: פרויקט Google Apps Script בחשבון המחלקה, כניסה בקישור אישי, והנתונים בחשבון בלבד.

## מה יש בתיקייה

| קובץ | מה הוא |
|---|---|
| `build.js` | בונה את התיקייה `dist/` מהקוד של האפליקציה (`public/`, `standalone/`) |
| `Code.gs` | צד השרת: שמירת הנתונים ב-Drive, משתמשים וקישורים אישיים, איתור כתובות, גיבוי לילי |
| `gshim.js` | מחבר את האפליקציה לשרת במקום לשמירה בדפדפן |
| `admin-ui.js` | חלון "משתמשים" למנהלי מערכת |
| `dist/` | מה שנדחף ל-Google עם clasp (לא עולה ל-GitHub, כי `Seed.gs` מכיל את מאגר העסקים) |

## בנייה

```
node google/build.js --data ..\mashgichim-app\data
```

`--data` היא התיקייה עם `db.json` (מאגר 510 העסקים). אפשר במקום זה `--seed-html "<קובץ ניהול כשרות - ללא שרת.html>"`.

## הקמה ראשונה (פעם אחת)

1. בתיקייה `google/dist`: `clasp create --type webapp --title "ניהול כשרות – מחלקת הכשרות" --rootDir .` ואז `clasp push -f`.
2. `clasp open-script` (או `clasp open`), בעורך בוחרים `setup` ולוחצים **Run**, ומאשרים הרשאות (Advanced ← Go to … ← Allow).
3. **Deploy** ← **New deployment** ← Web app. **Execute as**: `Me`. **Who has access**: `Anyone`.
4. בעורך בוחרים `adminLink` ולוחצים **Run**. ב-Execution log מופיע הקישור האישי שלך.
5. במערכת: **משתמשים** ← הוספת משתמש ← **שליחת קישור**.

## העברת הנתונים מהגרסה ללא שרת

בקובץ הישן: "טעינת קובץ" ← גיבוי והעברת נתונים ← **שמירת גיבוי לקובץ**. במערכת החדשה: "טעינת קובץ" ← גיבוי והעברת נתונים ← **טעינת גיבוי**.

## עדכון גרסה

`node google/build.js --data ...`, ואז בתיקייה `google/dist`: `clasp push -f` ו-`clasp deploy -i <deploymentId>` (המזהה מ-`clasp deployments`). הקישורים האישיים לא משתנים.

## הנתונים

- תיקייה **"ניהול כשרות – נתונים"** ב-Drive: קובץ JSON לכל סוג נתונים (דיווחים, עריכות, מיקומים…), `seed.json` עם מאגר העסקים, ותת-תיקייה **"גיבויים"** עם עותק מכל לילה (30 אחרונים). קובץ גיבוי אפשר לטעון דרך "טעינת גיבוי".
- גיליון **"ניהול כשרות – משתמשים"**: הקישורים האישיים. לא לערוך ידנית את עמודת token.
- שינויים של כמה משתמשים במקביל נשמרים לפי רשומה, כך שעריכה של אחד לא דורסת עריכה של אחר בעסק אחר. משתמש אחר רואה את השינוי תוך דקה.
- איתור מיקום לפי כתובת נעשה מהשרת של Google (OpenStreetMap, ואם צריך Photon), ולכן סינון הרשת במחשב לא חוסם אותו.
